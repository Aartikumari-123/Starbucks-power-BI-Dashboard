# Starbucks-power-BI-Dashboard
Starbucks Beverage Analysis Dashboard | Power BI

This project is an interactive Starbucks Beverage Analysis Dashboard created using Microsoft Power BI. The dashboard provides a visual analysis of Starbucks beverages across different categories and key nutritional attributes.

Project Overview

The dashboard analyzes Starbucks beverages based on:

- Total number of beverages
- Average calories
- Average sugar content
- Average caffeine content
- Beverage category distribution
- Caffeine comparison across beverage categories
- Calorie comparison across beverage categories
- Top 5 beverages with the highest caffeine content
- Starbucks global presence

Tools & Technologies

- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculations and measures
- Data Visualization for interactive charts, KPIs, and filters

Key Features

The dashboard includes interactive KPIs, charts, slicers, and visualizations that make it easy to explore beverage data and identify useful patterns and comparisons.

Objective

The main objective of this project is to demonstrate data cleaning, data transformation, DAX calculations, data visualization, and analytical skills using Power BI.

Project Outcome

This dashboard provides a clear and interactive way to understand Starbucks beverage characteristics and compare different beverage categories based on nutritional and caffeine-related metrics.
